## 过程中踩到的坑（都记下来了）

**① 我用 PowerShell 批量替换宽度，把 12 个文件的中文编码弄坏了** ✗
`Get-Content` 不带 `-Encoding` 会按系统默认（GBK）读 UTF-8 文件 ✓
发现方式是两个同类文件一个乱码一个正常 ✓ 恢复方式是从 git 取回 ✓
重做时改用 `[IO.File]::ReadAllText(..., UTF8)` ✓ 并加了编码复核 ✓ 现在 0 个乱码文件 ✓

**② 恢复操作连带回滚了未提交的编辑** ✗
展示页的 `highlightId` 就是这么丢的 ✓ **是线上验证把它抓出来的** ✓
公开页 10 枚星有 10 层细光芒 ✓ 但大光芒数为 0（应为 1）✓
**两个数字对不上就说明有东西没同步** ✓ 只看"细光芒在不在"会漏掉 ✓

**③ 两个 lint 错误都是我自己犯的** ✗
`react-hooks/purity`（渲染里用了 `Date.now()` ✓ 这个仓库只允许 `new Date()` ✓）
与 `react/no-unescaped-entities`（JSX 里用了英文直引号 ✓）✓

**④ 一次误判** ✗
我用 `.click()` 触发提交按钮 ✓ 读到的角标没变 ✓ 就判成"切换没生效" ✓
实际是**当时还没重渲染完** ✓ 下一次测量显示分母已经是 `/30` ✓
是我读数太快 ✓ 不是功能有问题 ✓
